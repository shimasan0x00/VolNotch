## 短い説明（Short Description）

```
メディア音量の刻みが粗くて「もう一段だけ下げたい」に届かないタブレット向けの、小さな音量補助アプリです。音量インデックスを 1 刻みで直接指定でき、さらに出力全体を dB 単位で減衰することで、最小の 1 段階よりもさらに静かに絞れます。外部ライブラリなし・ネットワーク通信なし・データ収集なし。
```

## 長い説明（Long Description）

```
VolNotch は、タブレットのメディア音量をハードウェアの刻みより細かく絞るための小さな補助アプリです。

■ なぜ必要か
多くのタブレットのメディア音量は内部的に十数〜25 段階程度しかありません。25 段階の端末では 1 段階が 0〜100 換算で約 4（＝4%）にあたり、音量ボタンではこれより細かく変えられません。就寝前や静かな部屋では「最小の 1 でもまだ大きい」ということが起こります。

■ できること
・音量インデックスの直接指定
　選択中のストリームの現在値を「現在値 / 最大値」で大きく表示し、スライダーまたは「−」「+」ボタンで 1 刻みに設定できます。「音量を 1 にする」ボタンで一気に最小へ。最大インデックスは端末ごとに自動取得するため、機種に依存しません。

・出力全体の微調整（dB 減衰）
　インデックス 1 でもまだ大きいときのために、出力全体を dB 単位で減衰できます。「0 dB に戻す」でいつでも元通りです。

・ストリームの切り替え
　メディア / 着信音 / 通知 / アラーム / システムを画面上部で切り替えられます。

・表示の自動追従
　物理の音量ボタンや他アプリで音量が変わっても、画面表示は自動で追従します。

・減衰の常駐と解除
　減衰中は「VolNotch 全体減衰: −X dB」という通知が常駐し、他アプリの使用中やアプリを閉じた後も減衰が維持されます。通知の「解除」またはアプリ内の「0 dB に戻す」でいつでも停止できます。

■ プライバシー
外部ライブラリを一切使用せず、ネットワーク通信も行いません。個人情報を含むいかなるデータも収集・送信しません。

■ 動作環境と制限
・Android 9（API 28）以降のタブレットに対応しています。
・「全体の微調整」は端末の音声処理機能に依存します。非対応の端末では、その機能のみ「この端末では全体の微調整を使用できません」と表示され無効になります（音量インデックスの調整は引き続き使用できます）。
```
